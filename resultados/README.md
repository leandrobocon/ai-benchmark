# Resultados

Resultados públicos do benchmark devem ser colocados nesta pasta.

## Regra de publicação

Não publicar resultados, prompts, respostas ou configurações que contenham informações internas, credenciais, dados pessoais ou detalhes de ambientes institucionais que não tenham sido preparados para divulgação.

## Formato recomendado

Cada conjunto de resultados deve informar:

- data;
- versão do benchmark;
- modelo;
- hardware/ambiente relevante;
- parâmetros relevantes;
- número de execuções;
- pontuação obtida;
- limitações ou observações.

Resultados devem ser apresentados como evidência de uma execução específica, e não como ranking universal de modelos.
